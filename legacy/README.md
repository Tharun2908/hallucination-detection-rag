\# Legacy Experiments



This directory contains earlier experiment iterations retained for provenance.



These files are not the canonical reproduction path for the final audited thesis results. During the project, several protocols were revised to address issues such as evaluation leakage, train/test threshold selection, group-disjoint splitting, exact example matching, and consistency between reported metrics and final thesis tables.



The active repository directories contain the final audited experiment paths used for the submitted thesis and subsequent verification.



For current reproduction and interpretation, use the canonical scripts and result artifacts documented in the root `README.md`.



Legacy files are preserved so that the experimental history remains inspectable rather than being deleted.
